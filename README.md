# 한·몽 번역기 (Korean ↔ Mongolian Translator)

한국어와 몽골어를 오가는 무료 번역 웹앱입니다. 설치 없이 브라우저에서 바로 쓸 수 있고, 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다.

## 주요 기능

- **한국어 ↔ 몽골어 번역**: 방향 전환 버튼으로 두 언어를 자유롭게 바꿔 번역합니다.
- **영어발음(채팅 줄임말) 자동 복원**: 몽골 사람들이 채팅에서 쓰는 영어발음 표기(예: `sain bainuu`, `hairtai shu`)를 키릴 문자로 되살려 번역합니다.
- **채팅용 몽골어 영어발음 강조**: 한국어를 번역하면 키릴 문자와 함께 `ü`·`ö` 같은 특수문자 없는 영어발음(예: `Sain baina uu`, `Khairtai shuu`)을 크게 보여 주고, 원터치로 복사할 수 있습니다.
- **한글로 적은 몽골어 발음 입력**: `사인 바이나 우`, `바야르라라`, `하이르타이 슈`처럼 한글로 적은 몽골어 발음도 몽골어(키릴)·영어발음으로 바꿔 줍니다.
- **발음 보기**: 번역 결과의 읽는 법을 함께 보여 줍니다.
- **듣기**: 원문과 번역문을 소리로 들을 수 있습니다(브라우저 음성 합성 사용).
- **🎧 몽골어 원어민 발음**: 자주 쓰는 표현 12개를 실제 몽골어 원어민 음성(신경망 음성)으로 미리 담아 두어, 휴대폰에서도 바로 들어 볼 수 있습니다. 앱에 내장된 표현과 같은 문장을 번역해 듣기를 누르면 그 원어민 음성이 재생됩니다. 그 밖의 문장은 기기에 몽골어 음성이 있으면 그 음성으로, 없으면 러시아어 음성으로 키릴 글자를 읽어 줍니다(근사 발음).
- **자주 쓰는 표현**: 인사말 등 바로 눌러 쓰는 예문을 제공합니다.
- **번역 기록**: 최근 번역을 모아 두고 다시 불러올 수 있습니다.
- **다크 모드 / 라이트 모드**: 기기 설정을 따르거나 직접 고를 수 있습니다.
- **번역 엔진 선택**: 기본은 무료 엔진(MyMemory)이고, 설정에서 Gemini API 키를 넣으면 더 자연스러운 번역을 쓸 수 있습니다.

## 사용 방법

1. `index.html`을 열거나 배포된 주소로 접속합니다.
2. 입력창에 한국어 또는 몽골어를 적고 **번역** 버튼을 누릅니다.
3. 결과를 복사하거나 듣기 버튼으로 확인합니다.

휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 열립니다.

## 참고

- 모든 처리는 브라우저에서 이뤄지며, 입력한 문장은 번역을 위해 선택한 번역 엔진으로 전송됩니다.
- Gemini API 키는 사용자의 브라우저에만 저장되고 서버로 보내지 않습니다.
- 파일 하나(`index.html`)로 동작하는 정적 웹앱이라 별도 서버나 빌드 과정이 필요 없습니다. (`audio/` 폴더에는 원어민 발음 샘플 mp3가 들어 있습니다.)
